# 《灾厄：吉光片羽》项目预设包

这是一套**项目级预设**，用于让任何在此仓库工作的智能体（DeepSeek Harness、Codex 类工具或其他支持 `AGENTS.md` 的代理）快速进入状态：先守住灾厄正史与「吉光片羽」文体，再写代码。

它不是 DSH 的「智能体预设（Agent Preset）」，**不需要安装、不需要重启**：复制到模组仓库根目录即可生效。

> 需要 DSH 的「智能体预设」？另见 `preset/`：`preset-twinkle-fragment.patch.yml` 是已安装到 DSH profile 的 Agent 预设声明，负责身份与语言规则；本目录的 `AGENTS.md` + `docs/` 负责细节与规范，两者叠加使用。

## 二、怎么用

1. 把 `AGENTS.md`、`docs/`、`.gitignore` 复制到模组仓库根目录（`Calamitytwinklefragment/`）。
2. 让智能体先读 `AGENTS.md`；它会在处理本仓库任务时自动加载。
3. 写设定前，按 `AGENTS.md` 的索引读 `docs/lore/`；写代码前读 `docs/dev/`。
4. 新增任何内容后，按 `AGENTS.md` §十 自检。

> 若你的工具只读取单个 `AGENTS.md`，可以把 `docs/lore/04-fragments.md` 与 `docs/lore/00-canon.md` 的关键段落摘进 `AGENTS.md`；但推荐保留分层，避免上下文过载。

### DSH 用户：再启用 Agent 预设

项目文件解决「细节在哪」，DSH 预设解决「你是谁」。预设已写入
`%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml`，在 **设置 → 智能体预设** 中选择「灾厄：吉光片羽」即可；重装与回滚见 `preset/README.md`。

## 三、这套预设的核心主张

1. **正史不可改写，只补空白。** 官方已定的事件、结局、生死、力量层级一律不动。
2. **「吉光片羽」是物证，不是百科。** 官方用亚利姆的低语讲历史；我们用一张订单、一则广告、一页论文讲同一段历史。
3. **碎片必须有出处、有立场、有残缺。** 没有「谁在什么处境下写的」，就不写。
4. **神是代价，不是答案。** 原创神的力量必须能算账：领域、金源魄、飞升方式、代价。
5. **先设定，后代码。** 代码可以为叙事改数值、改掉落、改触发；叙事不为代码让路。

## 六、维护

- 新增专名 → 先改 `docs/lore/05-glossary.md`。
- 新增事件 → 先改 `docs/lore/03-events.md`，再写碎片。
- 新增神明 → 先改 `docs/lore/02-gods.md`，填完档案卡再进代码。
- 发现正史更新 → 改 `docs/lore/00-canon.md`，并在条目里注明来源与日期。
- 文档版本建议跟随模组版本（当前 `0.1.2`）。
