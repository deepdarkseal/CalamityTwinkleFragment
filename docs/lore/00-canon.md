# 正史基线（Canon Baseline）

> 用途：本文件是《灾厄：吉光片羽》一切设定的**事实底座**。写任何涉及官方人物、事件、地点、力量的文本前，先在这里核对。
> 读法：先看「不可动摇的十条」，再看年表与档案。带 `[半官方]` 的内容可以用，但不要当成游戏内原文引用。

## 1. 纪元总表

| 纪元 | 时间 | 一句话 |
|---|---|---|
| 巨龙时代（Draconic Era） | B.A.C. ？ – 1037 | 金源巨龙统治地表，世界之魂碎裂后各龙分掌领域 |
| 灰色纪元（Gray Period） | 1037 – 约 1300 | 克希洛克飞升，诸神取而代之，金源巨龙被猎杀至近乎灭绝 |
| 神攫时代（Deific Era） | 约 1300 – 1781 | 神明秩序稳固；嘉登苏醒；伊尔梅里斯建国；亚利姆出生 |
| 圣战（The Crusade） | 1781 – 1887 | 亚利姆与犽戎讨伐诸神，持续百余年 |
| 灾厄（The Calamity） | 1887 – | 亚利姆退守巨龙天巢，泰拉人登场 |

> 历法：**阿萨福勒历（AC, Azafurian Calendar）**，以阿萨福勒建城为 AC 1。之前记作 B.A.C.。12 个月制，日期写法沿用现实习惯（如 `1803-06-30`）。
> 注意：AC 年表本身是 `[半官方]`，官方从未发布确定时间线。**本模组可以补细节，但不能改动已给年份的先后关系。**

## 6. 不可动摇的十条

写新设定时逐条对照；任何一条被触碰，就要停下来改稿或标 `[分歧]`。

1. **金源魄是硬规则**：神明的领域来自其吞噬的金源魄；没有金源魄就没有「正统神格」。
2. **克希洛克不可战胜**：官方明示已知力量无法击败他；原创存在不得凌驾其上。
3. **月亮领主只被封印，未被彻底消灭**：它屠杀了半数金源巨龙，并使「重生」领域失效。
4. **犽戎是最后一条金源巨龙**，且会重生；杀他≠永久消灭。
5. **亚利姆没有被击败**：1886 刺杀失败，他退守巨龙天巢，等待终局。
6. **阿萨福勒毁于 ~1870**：硫磺火元素苏醒 + 灾厄拦截，城市仍成焦土。
7. **伊尔梅里斯毁于 ~1875 大焚烧**：欧托妮露死亡，海神失踪，王国变沙漠。
8. **灾厄（Calamitas）在 1875 后失踪**：她封印了永冻，而非杀死他。
9. **嘉登在 1876 后被实质解雇**，但仍自行其是；星流机械三巨头在 1887 前后完成。
10. **腐化与猩红源自被草率处理的神尸**；神圣之地源自仁慈神明的精华。

## 8. 常见误写与纠正

| 误写 | 纠正 |
|---|---|
| 「亚利姆杀死了所有神」 | 大部分神被杀，但克希洛克、席尔瓦、史莱姆之神等存续；且圣战并未成功 |
| 「灾厄是反派，所以她说的话可信」 | 灾厄是不可靠叙述者之一；本模组应让她的话带自责与偏差 |
| 「月神是灾厄官方神明」 | 不是。露娜蒂卡是本模组原创，必须标 `[原创]` |
| 「血神是一个独立的新神」 | 血神即毁灭魔像，是祭献之神尸体死灵术复活的失败产物 |
| 「伊尔梅里斯是被海水淹没的」 | 是被灾厄焚烧、蒸发海水后变成沙漠；「沉沦之海」是其遗迹 |
| 「阿萨福勒一直存在到现代」 | ~1870 已焚毁；现存的是废墟与硫火之崖 |
| 「金源魄可以随便造」 | 金源魄是巨龙吸收世界之魂碎片而成；人类无法「制造」，只能夺取/继承 |
