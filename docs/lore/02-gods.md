# 神明谱系

> 用途：每位神一张**档案卡**。写台词、写碎片、写 Boss 设定前先查这里，确认「他能知道什么、能做什么、会怎么说」。
> 正史神明只做摘要，细节回 `00-canon.md`；原创神明是**草案**，标 `[原创·待定]`，作者确认后才可当定论使用。

---

## 0. 怎么用这张表

每张卡固定字段：

```
称谓 / 英文 / 领域 / 金源魄 / 升神方式 / 状态 / 性格 / 语言风格 / 与玩家关系 / 写作要点 / 禁止写法
```

- **语言风格**是最容易被忽略、也最影响质感的一栏。写台词前必看。
- **禁止写法**列出该角色最容易 OOC 的方向。
- 原创角色的 `[原创·待定]` 字段，在作者确认前**不得写进代码文本**，只能出现在文档与草案里。

# 一、正史神明（摘要）

## 克希洛克 Xeroc

- **领域**：原初之光（太阳）
- **金源魄**：泽拉托斯，原初光辉巨龙
- **升神**：1037 年，龙王垂死之际，以仪式 + 终末石吞噬其魂，自封第一位神明
- **状态**：存续。行踪、目的、计划全部不明；官方明示「已知无法战胜」
- **性格**：平静、疏离、近乎非人；不解释，不劝诱，不威胁
- **语言风格**：短句、陈述、留白。像在说一件早已发生的事
- **与玩家**：以 Boss Rush 试探泰拉人，不满意，给一块天巢的石头作安慰奖
- **写作要点**：他是**唯一不该被写透的角色**。每次出场只透露一个信息，且不解释
- **禁止写法**：不要让他长篇大论；不要让他被击败；不要让他「其实一直在保护世界」这种洗白

## 席尔瓦 Silva

- **领域**：生命 / 自然
- **金源魄**：生命巨龙（领域与龙魂相符，与克希洛克并列的特例）
- **状态**：被亚利姆重创后抛入深渊，沉睡再生；官方称她苏醒时泰拉人的旅程已结束
- **性格**：仁慈、坚定、有母性，但不软弱；对亚利姆的圣战明确反对
- **语言风格**：温和、缓慢、多用自然意象；不诅咒，不嘲讽
- **写作要点**：她的「善」是有重量的——她庇护过布瑞莱尔，也庇护过始源妖龙
- **禁止写法**：不要写成无脑圣母；不要让她在 1887 年前完全苏醒

## 普罗维登斯 Providence

- **领域**：灰烬 / 烈焰（亵渎之焰）
- **金源魄**：烈焰巨龙
- **升神**：与三名同伴击杀烈焰巨龙后，独吞金源魄；三同伴被赐予力量，成为亵渎守卫
- **状态**：游戏内被泰拉人击杀
- **性格**：狂信、绝对、以「终结苦难」为名的灭绝者；对守卫有真实感情（矛盾的裂缝）
- **语言风格**：宣教式、排比、火焰意象；把屠杀说成「净化」
- **写作要点**：她的逻辑是自洽的——生命即苦难，终结即慈悲。写她要写出**说服力**
- **禁止写法**：不要写成单纯疯子；不要让她承认自己错

## 欧托妮露 Otonilou

- **领域**：雷霆
- **金源魄**：风暴巨龙
- **状态**：~1875 大焚烧中被灾厄杀害
- **性格**：被描述为「好的统治者、圣人」
- **写作要点**：她死后，伊尔梅里斯的雷电防御体系随之失效——这是大焚烧能成功的隐性原因
- **禁止写法**：不要复活她；不要让她「其实逃走了」（海神才是失踪的那个）

## 海神 God of the Seas

- **领域**：海洋
- **状态**：大焚烧后失踪，推定死亡；官方未确认
- **写作要点**：**本模组最好的悬案之一**。可以留线索，但不要给答案
- **禁止写法**：不要明确写他死了或活着；不要让他成为幕后黑手（太廉价）

## 祭献之神 God of Sacrifices / 血神 毁灭魔像 The Ravager

- **领域**：祭献 →（死后）鲜血
- **状态**：祭献之神被亚利姆杀死；信徒以死灵术复活失败，诞生无智的血神；血神未被真正消灭，伏于献祭大教堂祭坛
- **性格**：无人格。只有饥饿、暴怒、模仿祭献仪式的本能
- **写作要点**：血神的恐怖在于**它记得仪式，却不记得为什么**
- **禁止写法**：不要给血神完整台词；不要把它写成「祭献之神的归来」

## 史莱姆之神 The Slime God

- **领域**：暴食 / 平衡
- **状态**：存续；诸神中最弱，靠战术逃避活过圣战
- **性格**：怯懦、精明、有自制力（克服暴食本性以维持平衡）
- **写作要点**：它是「弱者的生存智慧」的化身，可以写得很讽刺
- **禁止写法**：不要把它写成搞笑角色；它的懦弱是有代价的清醒

# 二、原创神明（草案）

> 以下两位是本模组现有 Boss。**人设、起源、领域均为草案**，需作者确认。
> 已实现事实来自代码（`Content/NPCs/BossGod/`），不可随意推翻；设定在此之上补完。

## 月女神 露娜蒂卡 Lunatica

**已实现事实**（来自代码与本地化，视为锁定）：

| 项 | 内容 |
|---|---|
| 类名 | `LunaGoddessLunatica` |
| 显示名 | 月女神 露娜蒂卡 |
| 召唤 | 使用「癫狂银月」召唤；需在月亮升起后 |
| 狂暴 | 日食时狂暴 |
| 专属减益 | `LunaLockedDebuff`「锁定」：月女神知道了你的位置，她的攻击将更加致命 |
| 弹幕 | 月蚀、月丝、银月盘、月神之镞 |
| 视觉母题 | 银、月、丝线、镞（箭）、锁定 |

**草案设定** `[原创·待定]`：

- **领域**：月相 / 梦魇 / 被注视
- **金源魄**：心灵巨龙金源魄的**残片**（月亮领主的天界柱以金源魄碎片铸成，事后散落；她得到的是残片，不是完整金源魄）
- **升神方式**：不完美飞升。她本是月亮信仰的祭司，在残片引导下完成仪式，缺终末石，领域漂移为「月相」
- **状态**：存续。只在夜间完整；日食时因月光被夺而暴走——这正是「狂暴」的设定解释
- **性格**：冷静、占有、把「被看见」当作恩赐。她不恨玩家，她只是不允许有人不被她看见
- **语言风格**：轻声、句子短、多用「看」「照」「留下」；不用感叹号
- **与玩家**：她把泰拉人当作「终于抬头看月亮的人」，因此既不放过，也不急杀
- **写作要点**：她的恐怖是**被注视的恐怖**——锁定减益就是她的神学
- **禁止写法**：不要写成病娇恋爱；不要让她在白天也全盛；不要给她「其实很孤独」的直白独白（用行为写）

**备选起源**（若作者不认可上案）：

| 方案 | 内容 | 优点 | 代价 |
|---|---|---|---|
| A（推荐） | 心灵金源魄残片 + 月亮信仰 → 月相/梦魇 | 与月亮领主、天界柱、月总线呼应；残片主题贴合「吉光片羽」 | 需确认「残片能否支持飞升」——建议设定为「勉强、残缺、短命的神」 |
| B | 死亡巨龙金源魄 → 月蚀/终结 | 与「月」的死亡意象贴合；力量层级自然偏低 | 与「生命与死亡」领域分配需额外解释 |
| C | 非金源魄的「伪神」：远古月亮信仰聚合成的残响 | 完全避开金源魄规则；适合写成「不是神的东西」 | 会削弱她作为「神」的分量，Boss 定位需改为「现象」而非「神」 |

## 腐败之主 Lord of Putrescence

**已实现事实**（来自代码与本地化，视为锁定）：

| 项 | 内容 |
|---|---|
| 类名 | `LordOfPutrescence` |
| 显示名 | 腐败之主 |
| 召唤 | 「腐败坩埚」召唤；提示「永恒的生命与腐烂」 |
| 机制 | 77 个腐烂流体、7 组分组更新、空间分区网格；高血量 |
| 专属减益 | `EternalDecayDebuff`「永恒腐败」：强大生命力带来的永恒腐蚀 |
| 视觉母题 | 腐殖、流体、坩埚、蜂群式小怪 |

**草案设定** `[原创·待定]`：

- **领域**：腐败 / 永恒生命
- **金源魄**：死亡巨龙金源魄的残片 + 阿萨福勒死灵术的「神尸处理失败」
- **升神方式**：不完美飞升。他是阿萨福勒的殡葬祭司，焚城后试图用残留的神尸与金源魄残片「保住」死者，仪式失控，他成了「不肯让任何东西结束」的东西
- **状态**：存续。被自己的领域困住——他无法停止腐烂，也无法死去
- **性格**：没有恶意，只有执念。他把吞噬称作「收留」，把腐蚀称作「保存」
- **语言风格**：缓慢、重复、像念名册；用「留下」「别走」「还来得及」
- **与玩家**：他不恨玩家，他想把玩家也「留下来」
- **写作要点**：他的悲剧是**爱变成了防腐剂**。恐怖来自温柔
- **禁止写法**：不要写成恶心怪物；不要写成单纯贪食；不要给他清醒的自我辩解

**备选起源**：

| 方案 | 内容 | 优点 | 代价 |
|---|---|---|---|
| A（推荐） | 殡葬祭司 + 神尸 + 死亡金源魄残片 → 腐败 | 与血神线（死灵术失败）形成对照；与阿萨福勒焚城直接挂钩 | 需确认「神尸 + 残片」组合不违反金源魄规则 |
| B | 被腐化/猩红感染的神明残骸自行聚合（类似腐巢意志） | 完全贴合正史「神尸会污染大地」 | 会失去「人味」，Boss 变成自然灾害 |
| C | 席尔瓦的失败造物：一次「永生」实验的副产品 | 与生命女神线呼应 | 会稀释席尔瓦的仁慈形象，慎用 |

# 四、跨神明写作规则

1. **神与神的对话极难写**。除非必要，不要让两位神直接对话；用第三方记录（碎片、祷词、战报）转述。
2. **神不解释自己的力量**。他们默认对方懂；不懂是对方的事。
3. **神的「人性」体现在取舍，不体现在抒情**。普罗维登斯为守卫复仇，比她说一百句「我也很痛苦」更有力。
4. **原创神不得评价正史神的对错**。他们可以有自己的立场，但不能充当作者的裁判。
5. **克希洛克不出场则已，出场必留白**。每次只给一个信息，且不解释。
