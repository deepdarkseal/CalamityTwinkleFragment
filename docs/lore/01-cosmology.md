# 世界观总纲

> 用途：解释这个世界**怎么运转**，以及本模组**为什么可以这样讲故事**。
> 写新神、新力量、新事件前读本文件；它与 `00-canon.md` 的分工是：00 记「发生了什么」，01 记「为什么能发生」。

---

## 1. 世界之魂与领域

太古的泰拉瑞亚拥有一颗**世界之魂**，涵盖存在的所有领域：生与死、原初之光、风暴、烈焰、重生……（`[半官方]`）

某一天，世界之魂**碎裂**了。碎片散落，每一片承载一个领域。金源巨龙吞下碎片，与自身灵魂融合，成为**金源魄（Auric Soul）**的持有者，各自掌管一个领域，成为世界的守护者。

要点：

- 领域不是「魔法属性」，而是**存在的一个侧面**。生命之神掌的是「活着」这件事本身，不是「治疗法术」。
- 领域有边界。重生之域能让人回来，但**前提是灵魂完整**；灵魂被吞噬或销毁，重生就失效——这正是金源巨龙灭绝的机制。
- 世界之魂碎裂的原因**官方未给出**。这是留白，可以写「众说」，但不能给定论。

## 2. 金源魄

| 问题 | 答案 | 级别 |
|---|---|---|
| 谁有金源魄？ | 金源巨龙；以及吞噬了金源魄的飞升者 | 半官方 |
| 能否人造？ | 不能。只能夺取、继承或吞噬 | 半官方 |
| 能否转移？ | 能。吞噬即转移；神明吞噬者以此闻名 | 正史 |
| 被吞后原主怎样？ | 灵魂缺失，重生失效，实质永久死亡 | 正史（Requiem / Yharon） |
| 金源魄会「消失」吗？ | 能量不灭，只会转移——神明吞噬者吞下的精华去了哪里，是官方悬案 | 正史（Devourer 条目） |

**写作约束**：

- 任何原创角色想成神，必须回答「金源魄从哪来」。答不上来，就不是正统神格。
- 不要发明「第二枚原初之光金源魄」这类设定；原初之光只有泽拉托斯 → 克希洛克这一条线。
- 「金源魄碎片」可以作为物品存在（如残响、龙鳞、龙羽），但它**不等于完整金源魄**，不能用来批量造神。

## 3. 飞升：正统与不完美

### 3.1 正统飞升

克希洛克的方法是**仪式 + 终末石（Terminus）**：一块魔法石碑，能让人「完美地」继承金源魄与对应领域。
官方文本明确：后来无数人仿效，但**除一人之外，所有人都缺少终末石**；他们确实成了神，**但领域在过程中发生了改变**。（`[正史]` Requiem 条目 + `[半官方]` 补述）

终末石被克希洛克封在深渊，由受席尔瓦祝福的始源妖龙看守。

### 3.2 不完美飞升（本模组最重要的创作接口）

「领域漂移」是正史给的机制，不是我们编的：

- 没有终末石 → 飞升成功，但**领域被扭曲**。
- 扭曲的方向，取决于三件事：所吞金源魄的原始领域、飞升者的执念、飞升时的处境。

这解释了本模组两位原创神的来源，也解释了为什么他们「像神又不像神」：

| 角色 | 原始领域（假设） | 执念 | 漂移后的领域 |
|---|---|---|---|
| 腐败之主 | 死亡 / 生命 | 拒绝一切终结 | 腐败、永恒生命、不死 |
| 月女神 露娜蒂卡 | 心灵 / 死亡 | 留住每一个梦 | 月相、梦魇、记忆 |

> 以上为**推荐方案**，状态 `[原创·待定]`，需作者确认。三种备选起源见 `02-gods.md`。

### 3.3 飞升的代价（建议统一设定）

为了让原创神有「灾厄味」，建议统一采用以下代价（可逐条取舍，确认后写入 `02-gods.md`）：

1. **记忆残缺**：飞升会烧掉一部分「作为人的记忆」，越强的神忘得越多。
2. **领域绑定**：离开自己的领域会衰弱。月神在白天衰弱，腐败之主离开腐殖环境会枯萎。
3. **信徒依赖**：力量与信仰相关（正史：普罗维登斯从信众处汲取力量）。没有信徒的神会饿。
4. **不可自杀**：神格会阻止宿主自我终结，只能被他人杀死或封印。

## 4. 神明的层级与力量尺度

从高到低（`[半官方]` 综合）：

1. **克希洛克**：原初之光，太阳之力，已知无法战胜。**天花板，不可超越。**
2. **金源巨龙**：泽拉托斯、犽戎。单体可镇压一个领域。
3. **顶级神**：普罗维登斯、席尔瓦。能灭国、能改地貌。
4. **一般神**：欧托妮露、海神、祭献之神、血神。能统治一个文明或一方领域。
5. **次级神 / 元素**：史莱姆之神、硫磺火元素、极地之灵。局部强大，但可被顶级凡人击败。
6. **凡人巅峰**：亚利姆、灾厄、布瑞莱尔、斯塔提斯。**能弑神，但不是神。**

**写作约束**：

- 原创 Boss 的定位建议在 4–5 级之间：**能被打败，但打败它有代价**。
- 不要让原创神「单手捏爆普罗维登斯」。要强，就在**规则**上强（领域、条件、代价），不在数值上吹。
- 玩家（泰拉人）的定位是「变量」：不在层级表里，但能改变层级表。

## 5. 元素（Elementals）与神明的区别

| | 元素 | 神明 |
|---|---|---|
| 来源 | 世界本源的某一方面（自然、热、水、冰） | 吞噬金源魄飞升 |
| 生死 | 只要领域不灭就杀不死，只能封印/放逐 | 可被杀死；金源魄可被夺走 |
| 心智 | 多数不完整（席尔瓦是例外） | 完整人格 |
| 例子 | 席尔瓦（自然）、硫磺火元素（热）、水元素、冰元素 | 普罗维登斯、欧托妮露、血神 |

**注意**：席尔瓦同时是「自然元素」与「生命女神」——她吞噬了生命巨龙的金源魄。这是特例，不是通例。写原创角色时不要随便把「元素 + 神」叠在一起。

## 6. 死亡、神尸与残响

正史给出的三条硬规则：

1. **神尸不会安静**。神明死后，其精华若未被妥善处理，会污染大地，形成腐化/猩红。
2. **死灵术是残缺的技艺**。它能让尸体动起来，但召不回本人；血神就是这么诞生的。
3. **残响（Echo）** 不是复活。残留的意志、习惯、口癖可以留在物件、地点、法术里，但它**不是那个人**。

这三条是本模组「碎片」存在的理论基础：碎片之所以能「低语」，不是鬼魂，而是**残响**——强烈意志在物证上的沉积。

> 写碎片时请严格区分：**残响 ≠ 灵魂 ≠ 复活**。残响只能重复、扭曲、片段式地回应，不能完整对话，不能提供全知情报。

## 7. 扭曲维度（The Distortion）

- 月亮领主来自扭曲；神明吞噬者与扭曲有更深关联；西格纳斯是扭曲中的存在。
- 斯塔提斯以「一臂一腿」为代价，与西格纳斯交易回到泰拉瑞亚。
- 布瑞莱尔仍被困在扭曲中。

**用途**：这是本模组处理「不可能的信息」的安全出口——来自扭曲的东西可以说出正史中无人知道的事，但**不可信、不完整、要付代价**。用它来解释碎片里的「越界知识」，比让某个角色突然全知更好。

## 8. 认识论：低语与物证

这是本模组的**叙事内核**，也是与官方内容对话的方式。

### 8.1 官方的「低语」

灾厄的传颂之物（Lore items）统一以「Whispers from on high dance in your ears... Hold Shift to listen closer」开头，内容是**亚利姆的叙述**。
官方明确提示：亚利姆的解读「明显狭隘」，玩家应当质疑。→ **官方叙事本身是不可靠叙述。**

### 8.2 本模组的「物证」

「吉光片羽」是同一种「按住 Shift 听」的形式，但内容不是某人的叙述，而是**物件本身**：

- 一张订单、一则广告、一篇论文、一份战吼、一页账本。
- 它不会替你总结意义，只会露出**写它的人当时在意什么**。
- 它可能说谎、可能残缺、可能被伪造——但它的谎言本身也是史料。

### 8.3 两者的关系

| | 传颂之物（官方） | 吉光片羽（本模组） |
|---|---|---|
| 声音 | 亚利姆，全知视角，带偏见 | 无名者，有限视角，带处境 |
| 时间 | 事后叙述 | 事发当时 |
| 可信度 | 高信息量、低可信度 | 低信息量、高可信度 |
| 功能 | 解释世界 | 让世界有质地 |

**写作公式**：官方低语告诉你「亚利姆说伊尔梅里斯该被烧」；吉光片羽给你「大焚烧前三个月的伊尔梅里斯旅游广告」。两者并置，历史才成立。

## 9. 本模组的五个叙事命题

写任何新内容前，问自己它在服务哪一条。服务不了的，大概率不该写。

1. **历史由胜利者低语，物证沉默但诚实。**
   → 碎片永远站在「没有资格写历史的人」那一边。

2. **神不是答案，是代价。**
   → 每一次飞升、每一场神迹，都要能算出一笔账。

3. **毁灭不是瞬间，是一层层剥落。**
   → 阿萨福勒不是「一天烧完的」，伊尔梅里斯不是「一天沉没的」。写过程，不写结果。

4. **被遗忘的不是小事。**
   → 一张订单上的乙方、一个护具厂的第三车间、一名没有名字的随军牧师，才是这个模组的主角。

5. **「吉光片羽」本身就是一种悲伤。**
   → 能留下来的，永远是最轻的东西：一片羽毛、一页纸、一句口号。重的都烧掉了。

| 知识边界 | 角色只知道他那个时代、那个位置能知道的事 |
| 力量表现 | 强在规则与代价，不强在数值 |
