# 原创事件年表

> 用途：把「吉光片羽」挂到具体的时间与地点上，确保每条碎片都有出处、有接口、不撞正史。
> 原则：**只在正史的缝隙里写**。官方给年份的，我们补月份与细节；官方没给的，我们才建事件。

## 3. 原创事件卡

> 全部标 `[原创·草案]`。确认后去掉「草案」，并把状态改为 `[原创·已确认]`。

### E-01 玛那护教军的成立 —— 约 1790s

- **地点**：阿萨福勒，第三铸造区
- **梗概**：圣战长期化，阿萨福勒的铸造行会与随军祭司团合并，成立「玛那护教军」：一半是军需官，一半是牧师。他们相信魔力是神明的恩赐，而锻造是把恩赐变成可携带的形式。
- **与正史接口**：阿萨福勒与亚利姆结盟、提供军工；阿萨福勒是多种魔法流派的发源地。
- **可产出碎片**：教团章程、入伍誓词、军需配额表、随军牧师的告解记录。
- **禁忌**：不要写成「亚利姆的秘密邪教」；它应是**体制内的军需教团**，有官僚气。

### E-02 第三护具厂的最后一班 —— 1803-06-30 之后数周

- **地点**：阿萨福勒，第三护具厂
- **梗概**：接到 F-03 的加急订单后，工厂连夜赶工；防火涂层配方来自一位不肯署名的老匠人。订单最终是否交付、交给谁，没有记录。
- **与正史接口**：圣战军工体系；硫磺火元素尚未苏醒（1870 才醒）。
- **可产出碎片**：配方残页、加班签工表、报废记录、匠人遗书。
- **禁忌**：不要在这里让硫磺火元素提前苏醒。

### E-03 伊尔梅里斯的最后一个夏天 —— 约 1874–1875

- **地点**：伊尔梅里斯，珊瑚宫外围的商业区
- **梗概**：王国被围近百年，仍维持着对外的旅游与贸易；旅行社照常营业，广告照常印刷。没有人相信首都会陷落。
- **与正史接口**：伊尔梅里斯长期被围、资源配给、依赖雷电防御。
- **可产出碎片**：F-01 旅游广告、船票、海关申报单、酒店留言簿、逃难者的行李牌。
- **禁忌**：不要写「大家都知道要完了」；要写**正常生活如何被维持**。

### E-04 焚后生态调查 —— 约 1876

- **地点**：沉沦之海，原伊尔梅里斯海域
- **梗概**：大焚烧后一年，一支混合调查队（伊尔梅里斯流亡学者 + 嘉登实验室的采样员）进入低氧海域，记录幸存物种。F-02 的论文是这次调查的产物之一。
- **与正史接口**：大焚烧导致生态毁灭与物种灭绝；嘉登在沉沦之海研究海棱晶。
- **可产出碎片**：F-02 论文、采样日志、潜水钟检修单、失踪人员名单。
- **禁忌**：不要让调查队发现「海神还活着」的实证；最多留下无法解释的异常。

### E-05 献祭大教堂的最后一次点名 —— 圣战期

- **地点**：献祭大教堂
- **梗概**：亚利姆攻入教堂、杀死祭献之神后，残存的信徒在废墟里完成最后一次仪式。他们不是要复仇，是要**把神叫回来**。仪式失败了，血神站了起来。
- **与正史接口**：祭献之神之死、死灵术的残缺、血神的诞生。
- **可产出碎片**：F-04 战吼、仪式流程单、献祭名册、被血浸透的家书。
- **禁忌**：不要让血神说话；不要把它写成「祭献之神归来」。

### E-06 月下的第一次点名 —— 1887 之后

- **地点**：夜晚的地表，月光直射处
- **梗概**：露娜蒂卡在某个夜晚「醒来」，开始点名——她能叫出每一个被月光照到的人的名字。被她叫到的人，会开始梦见同一片海。
- **与正史接口**：月亮领主封印后八百年，月亮上发生了什么（留白）；心灵金源魄残片（天界柱遗留）。
- **可产出碎片**：祷词、被划掉的名字、月相观测记录、失眠者的日记。
- **禁忌**：不要让月亮领主「通过她复活」；她与月总的关系只能是**残片与污染**，不是代理人。

### E-07 坩埚里的名册 —— 1887 之后

- **地点**：阿萨福勒废墟，硫火之崖
- **梗概**：腐败之主在焚城后一直做同一件事：把死者「收留」进自己体内，并念他们的名字。他已经念了一百多年，名册还没念完。
- **与正史接口**：阿萨福勒焚毁、神尸污染、死灵术失败。
- **可产出碎片**：名册残页、殡葬行会执照、防腐配方、孩童的识字课本。
- **禁忌**：不要让他「其实是在救人」这种直白反转；让玩家自己算这笔账。

## 4. 未使用的钩子（备选池）

需要新碎片时从这里挑，不必每次新造事件。

1. 阿萨福勒的**罢工**：护具厂工人拒绝为前线赶工，理由是「我们也在被烧」。
2. 圣战的**征兵海报**：画着亚利姆，口号是「为了没有神的日子」。
3. 伊尔梅里斯的**免税令**：为了留住商人，国王签下的最后一份经济文件。
4. 一名**随军牧师**的告解：他开始怀疑「玛那」是否真的存在。
5. 巨龙教的**借书卡**：地牢图书馆最后一位借阅者，借了一本关于「如何杀死不死者」的书。
6. 深渊的**采样瓶标签**：写着「勿开。开了就回不去了。」
7. 钨钢叛军的**传单**：印刷粗糙，错别字很多，但地址写对了。
8. 嘉登实验室的**报废单**：报废理由一栏写着「它开始问问题」。
9. 大焚烧当天的**潮汐记录**：海平面在几个小时内下降了。
10. 一份**未寄出的信**：收信人写的是「海神陛下」，邮戳是 1875 年之后。

```markdown
### E-XX <事件名> —— <时间>

- **状态**：[原创·草案] / [原创·已确认]
- **地点**：
- **时间**：（AC 年，可精确到月/日；不确定写「约」）
- **梗概**：（3–5 句，写「发生了什么」，不写「意味着什么」）
- **视角**：（谁在记录？他站在哪一边？）
- **与正史接口**：（接哪条官方事实；会不会改变官方结局）
- **可产出碎片**：（3–6 种载体）
- **禁忌**：（这个事件里绝对不能发生的事）
- **待确认**：（需要作者拍板的问题）
```

## 6. 一致性检查

新增事件或碎片后，逐条过：

- [ ] 年份落在正确区间，且不与同年其他事件冲突。
- [ ] 涉及的人物在那一刻**还活着、还在那个位置**。
- [ ] 没有提前/延后官方事件（如硫磺火元素 1870 才醒、嘉登 1803 才入伙）。
- [ ] 没有让角色知道他不该知道的事。
- [ ] 没有改变官方结局。
- [ ] 载体符合时代与技术（1875 年没有电子屏幕，但有印刷、电报、魔法通信）。
- [ ] 已登记到 `05-glossary.md` 与本节年表。
